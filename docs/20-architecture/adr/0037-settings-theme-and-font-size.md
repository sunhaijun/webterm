# ADR-0037 设置回来，只有两项：主题与终端字号；会话抽屉有最小高度、底部留出呼吸空间

状态：已接受（2026-10-31）。**部分取代 [ADR-0030](0030-no-settings.md)**：§1 的「主题只跟随系统、字号固定、没有设置入口」与 §2 的「浮层只剩底部 sheet」。ADR-0030 §1 里「字体固定为系统等宽栈」、「`Ctrl+Shift+,` 不拦截」，以及 §3 的会话按钮，都保持不变。再次修订 [ADR-0018](0018-one-drawer-primitive.md) 的浮层形态。

## 背景

ADR-0030 把设置整个删掉之后，用户又提出：

> 可能还需要一个简洁的配置页面，跟此前位置一样即可。但是仅需要设置主题色，还有字号大小，其他仍保持默认即可。

同一轮里还有三条：

- 手机的会话抽屉在会话少的时候太矮（一个会话时只有标题栏、一行、一个按钮）。
- 抽屉底部的按钮和屏幕底边之间一点间距都没有，布局要有呼吸空间。
- 设置按钮的图标要和已有图标风格一致。老的 ⚙ 是 Unicode 字符：各平台字形不同，有的还渲染成彩色 emoji，和标签栏里线条画的 `+`（[ADR-0035](0035-tabbar-new-button-pinned.md) §3）不是一路。

ADR-0030 删设置的理由有两条，现在这一版都照顾到了：一是项目太多、要解释，这次只留两项，界面上也不写说明（[ADR-0028](0028-settings-without-notes.md) 的原则）；二是换设备要重设，这一点照旧，但默认值已经是按设备挑过的，大多数人不必去改。

## 决策

### 1. 只有两项设置

| 项 | 取值 | 默认 | 存储（`localStorage`） |
|---|---|---|---|
| 主题 | 跟随系统 / 浅色 / 深色 | 跟随系统 | `webterm.theme`：`system` / `light` / `dark` |
| 终端字号 | 10–24px 的整数，步长 1 | 14px | `webterm.fontSize` |

- **主题**：选浅色或深色时，`<html>` 打上 `data-theme`，界面与 xterm 一起换，不用刷新；选跟随系统时去掉这个属性，回到 `prefers-color-scheme`。强制的那一种同时设 `color-scheme`，滚动条与原生控件跟着变。**主题在首次渲染之前就打上**（`main.tsx`），配对页、闸门页也一样，没有先亮后暗的闪烁。
- **字号**：所有 xterm 实例一起换，对当前的那个 `fit()`，**再补一条 `resize`**。字符格变了而容器没变，`ResizeObserver` 不会响，漏发就是客户端和 PTY 的 cols/rows 分家（老 AC-5.3 的那条坑）。列数一变，agent 照例重发快照（[ADR-0026](0026-agent-holds-terminal-state.md) §4）。
- **字号只存一份，不按形态分**。形态由屏幕短边决定，在一台设备上永远不变（[ADR-0025](0025-termux-style-ui.md) §1）；`localStorage` 又是按浏览器存的。按形态各存一份，在同一台设备上永远只用得到其中一份。
- **字体不进设置**，仍是系统等宽栈（ADR-0030 §1）。
- **改了立刻生效**，没有「保存」，也没有预览行：浮层后面就是终端本身。
- 读不到存储（隐私窗口、禁用站点数据）或值不合法时用默认值，不报错。老版本留下的 `webterm.fontSize.compact` / `.wide`、`webterm.font.family` 不读。

### 2. 入口回到原来的位置，不加快捷键

- `wide`：标签栏最右边，连接状态点的右侧，`data-testid="open-settings"`，36px 宽，与 `+` 同高。
- `compact`：会话抽屉底部，「+ 新会话」的右侧，一个 48px 的方形按钮，`open-settings`。点它先关会话抽屉，再开设置。
- **不恢复 `Ctrl+Shift+,`**：它照旧交给终端（ADR-0030 §1）。设置一年改不了几次，不值得占一个组合键。

### 3. 图标：一套线条图标

界面上自己画的图标统一成一种画法：**内联 SVG，只描边不填充，`stroke="currentColor"`，线宽 1.75px，端点与拐角都是圆的**。用到的地方：

- 标签栏的 `+`（已经是，ADR-0035 §3）与 ⚙；
- 会话抽屉底部的 `+`（原来是字符「+」）与 ⚙；
- 设置里字号的 `−` / `+`。

⚙ 画成一个六齿的齿轮（外轮廓 + 中间一个圆孔），14×14 与 `+` 同框。颜色跟着按钮走：平时 `--muted`，悬停 `--fg`。

### 4. 浮层按形态分两种

| | `compact`（手机） | `wide`（PC / Pad） |
|---|---|---|
| 形态 | 贴底整宽 sheet：抓手、下滑关闭 | 居中浮窗，宽 `min(420px, 100vw − 32px)`，圆角 14px |
| 用它的 | 会话抽屉、设置 | 设置 |

按形态分，而不是像 ADR-0018 当初那样按 `pointer`：Pad 是触屏，但屏幕宽，一条横贯 1024px 的底部 sheet 里放两行设置，左右全是空的；iPadOS 自己的模态也是居中的。会话抽屉只出现在 `compact` 上，所以它恒为 sheet。

关法不变：点遮罩、`Esc`、✕、（sheet）下滑。设置不接系统返回键：从会话抽屉切到设置时，抽屉要 `history.back()` 消掉自己那条记录，那是异步的，紧接着设置再 `pushState`，两者的先后不可靠。关掉设置后，打开之前焦点在终端（或文本输入页）里的、或者是非触摸设备，把焦点还回去。

### 5. 会话抽屉的高度与底部留白

- **最小高度 50% 视口**，最大仍是 80%。一半是 iOS sheet 的「中等」档，会话少的时候不至于只剩一条。多出来的高度给列表，底部那一行始终贴着 sheet 的底部。设置 sheet 内容只有两行，不设最小高度。
- **底部一行留出呼吸空间**：上 12px、左右 16px、下 `max(16px, env(safe-area-inset-bottom))`。按钮 48px 高、圆角 12px、`--surface` 底色加一圈 `--line` 细边，两个按钮之间隔 12px。不再是贴边铺满的平按钮。
- 没有底部一行的 sheet（设置）同样在底部留 `max(16px, env(safe-area-inset-bottom))`。

## 不采纳的方案

- **主题之外再给强调色可选**。用户说的「主题色」按此前的设置理解为主题（深浅色）；强调色专门表达「选中的是这个」（[layout.md](../../40-frontend/layout.md) §主题），换成别的颜色要在两种底色下各验一遍对比度，又多一个项。
- **字号用数字输入框**（老设置面板的做法）。手机上一点就弹数字键盘，把下半屏挡住；`−` / `+` 一下一格，不弹键盘。
- **主题用下拉框**。三个选项平铺成分段按钮，一眼看到当前是哪个，点一下就换。
- **字号按形态各存一份**。见 §1。
- **浮层按 `pointer` 分形态**。见 §4。
- **设置做成整页（路由）**。两行设置配不上一整页，也会打断终端。

## 后果

- AC-5.3 改写为「外观有两项设置」；AC-5.11 改成两种浮层形态，并加上会话抽屉的最小高度和底部留白；AC-4.10 的抽屉底部改成「+ 新会话」与 ⚙。
- E2E-12 ② 改成验证默认跟随系统、改主题与字号、刷新后保留；E2E-28 ① 底部多一个 `open-settings`，新增 ⑦（高度与留白）、⑧（从抽屉进设置）；E2E-41 ① 标签栏最右有 `open-settings` 并与状态点对齐，新增 ⑩（居中浮窗、关后焦点回终端）。
- 前端新增 `ui/prefs.ts`（读写两项偏好、打主题）与 `app/settings.tsx`；`Drawer` 重新按形态分两种；SessionStore 恢复「所有实例一起改字号」；控制器的 `measure` 恢复 `force`。CSS 里深色变量又要写两遍（媒体查询里一份，`[data-theme=dark]` 一份）。
- m10 的双指捏合改字号若做，改的就是这里的同一个值。
