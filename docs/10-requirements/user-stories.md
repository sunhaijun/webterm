# 用户故事

> 状态：Accepted

单用户工具，"我"指唯一使用者。每条故事标注所属里程碑（见 [`../90-roadmap/milestones.md`](../90-roadmap/milestones.md)）。
每条故事都有对应的验收标准，见 [`acceptance-criteria.md`](acceptance-criteria.md)。

---

## US-1 部署与访问

**US-1.1**（m2）作为使用者，我把一个二进制拷到服务器上执行，就能得到一个带合法 HTTPS 证书的可访问服务，不需要装 nginx、不需要手动申请证书、不需要改 DNS 以外的任何东西。

**US-1.2**（m2）第一次访问时，我在服务器终端上看到一个二维码，用手机扫一下就完成了授权，之后这台手机再也不用登录。

**US-1.3**（m2）我能看到所有已授权设备的列表，能单独吊销某一台（比如手机丢了），也能一键吊销全部。

**US-1.4**（m6）我能把 webterm 添加到手机主屏，打开后没有浏览器地址栏，跟原生 App 一样。

---

## US-2 永不断线

**US-2.1**（m1/m3）我在地铁里网络断了 20 秒，恢复后终端画面**接着原来的位置继续长**，不是重画、不是空白、不是要我按回车刷新。

**US-2.2**（m1/m3）网络断的那两秒我正在打字，恢复后我打的字**没有丢**，全部按顺序进入了终端。

**US-2.3**（m3）我合上笔记本，两小时后打开，会话还在，中间跑完的构建输出还在（只要没超出缓冲上限）。

**US-2.4**（m3）如果断开太久导致缓冲被覆盖，我能明确看到"历史输出已截断"的提示，而不是拿到一屏乱码却不知道发生了什么。

**US-2.5**（m3）我能随时看到当前连接状态：在线 / 重连中 / 已恢复。恢复时告诉我补了多少内容。

---

## US-3 输入体验

**US-3.1**（m4）我要给终端里的 AI agent 写一段 300 字的中文 prompt。我在一个**正常的输入框**里写，输入法候选框位置正确，可以随意修改、换行、粘贴，写完一次性提交。

**US-3.2**（m4）我在 vim 里按 `:wq`、在 htop 里按方向键、用 Ctrl+C 打断命令 —— 按键都正常直通，没有被输入框拦住。

**US-3.3**（m4/m5）上面两种情况之间的切换是**自动**的：停在 shell 提示符时给我输入框，有程序在跑时给我直通。我不需要理解"模式"这个概念，但需要时能手动锁定。

**US-3.4**（m4）在手机上，软键盘弹出时布局不会乱跳，终端内容不会被键盘盖住。

**US-3.5**（m4）在手机上我能按到 `Esc`、`Tab`、`Ctrl`、方向键和 `|` `~` `/` `-` 这些软键盘上没有的键。

**US-3.6**（m4）我粘贴一段多行文本进去，不会被 shell 当成多条命令逐条执行（bracketed paste）。

---

## US-4 多会话

**US-4.1**（m6）我能同时开多个会话：一个跑构建、一个看日志、一个改代码，互不干扰。

**US-4.2**（m6）切换会话在手机上是一个手势或一次点击的事，不需要精确点击小标签。

**US-4.3**（m6）我切走的会话继续在后台跑。如果它产生了新输出，我能在会话列表上看到未读标记。

**US-4.4**（m6）会话名字自动是它当前所在目录的名字（比如 `webterm`），不是 `Session 1/2/3`。我也能手动改名。

**US-4.5**（m6）会话里的 shell 退出后，我还能看到它最后的输出，而不是标签直接消失。

---

## US-5 阅读输出

**US-5.1**（m3）我能直接用滚动手势回看历史输出，不需要进入任何"模式"。

**US-5.2**（m6）我能在当前会话的历史输出里做文本搜索，命中处高亮并能逐个跳转。

**US-5.3**（m6）我能调整字号。手机竖屏、手机横屏、平板、桌面各自有合理的默认值。

**US-5.4**（m6）我能选中并复制输出里的文本，长选择不会因为自动滚动而丢失。

---

## US-6 命令历史与快捷命令

**US-6.1**（m5）我执行过的每条命令都被记下来了，包括它的退出码、耗时和执行目录。

**US-6.2**（m7）我能搜索历史命令（按原文、按目录），点一条就填进输入框，改两个字再回车。

**US-6.3**（m7）我在历史列表里点一下星标，这条命令就成了快捷命令，置顶显示。

**US-6.4**（m7）在手机上，我最常用的几条快捷命令是底部一排可以横滑的按钮，一点就填进输入框。

**US-6.5**（m7）我能给快捷命令起个短名字（比如"重启服务"），能拖动排序，能取消置顶。

**US-6.6**（m7）在桌面上按一个快捷键就打开命令面板，在里面能模糊搜索会话、快捷命令和历史，一个入口搞定所有事。

**US-6.7**（m5）以空格开头的命令不进历史（沿用 shell 的 `HISTCONTROL=ignorespace` 习惯），这样我贴 token 的时候不会被记下来。

**US-6.8**（m7）我能删除单条历史记录，也能清空全部历史。

---

## US-7 降级与可诊断

**US-7.1**（m5）如果 shell 集成没生效（换了 shell、配置冲突），终端**照常可用**，只是没有历史、没有 CWD 显示、模式需要手动切。界面上有一个不打扰的提示告诉我这件事和怎么修。

**US-7.2**（m2）证书申请失败时，我在服务器终端上看到的是"为什么失败 + 怎么修"，不是一行 Go 的 error 堆栈。

**US-7.3**（m6）会话数达到上限时，我看到明确提示，而不是新建按钮点了没反应。
