## 真实网络（m3 后每次都要过）★

这是"永不断线"承诺的真实验证，自动化只能模拟。

- [x] Wi-Fi → 4G 切换：跑着 `emit.sh`，切网，屏幕**接着长**，不重画不空白
- [x] 地铁 / 电梯：进隧道断 30 秒，出来自动恢复，内容完整
- [x] 飞行模式开 2 分钟再关：恢复（可能触发截断提示，但后续输出正确）
- [x] 笔记本合盖 2 小时再打开：会话还在，中间的输出还在
- [x] 断网期间在 Composer 提交三条命令 → 恢复后按顺序执行，不丢不重
- [x] 弱网（限速到 100kbps）下滚动与输入仍可接受
- [x] 状态指示器的三态在真实网络下都出现过，"补齐 N KB" 的数字合理
